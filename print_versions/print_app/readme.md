# 🧠 PrInt - Pré-Diagnóstico Inteligente

## 📱 Sobre o Projeto
**Aplicativo - Desafio PWA**  

Este projeto faz parte do desafio de criação de um **Progressive Web App (PWA)**.  
O objetivo é transformar a página em um aplicativo funcional utilizando **HTML, CSS e JavaScript** no mesmo arquivo (`index.html`), além de incluir `manifest.json`, `service-worker.js` e os ícones do app.

## 💡 O que é o PrInt
O **PrInt** é uma plataforma de **pré-diagnóstico médico inteligente** desenvolvida com o objetivo de auxiliar o usuário na **detecção precoce de doenças** e no **direcionamento ao profissional de saúde adequado**.  

O PrInt representa o futuro da triagem digital — um sistema que conecta tecnologia, empatia e prevenção para cuidar de quem mais precisa. Por meio de **inteligência artificial**, o sistema analisa sintomas relatados e sugere possíveis condições médicas, funcionando como uma ferramenta de apoio — e não substituição — à avaliação clínica.

## 🌍 Nossa Visão
Queremos **revolucionar o acesso à saúde** no Brasil, tornando o atendimento médico mais rápido, eficiente e acessível.  

## ⚙️ Funcionalidades Implementadas Até o Momento
